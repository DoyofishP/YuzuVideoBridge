## 分段记忆

**01｜sheet_001 + sheet_002｜00:00–00:23。** 清早，银白发龙族女子 GPT 站在新石屋门口，手里握着发光的火焰棒/烈焰棒，感慨“下界要塞也不过如此”，说明她已完成上集布置的下界搜集任务。但看到门外还躺着戴黑色睡眠眼罩的苦力怕，她立刻吓一跳。浅蓝发种田女子探出门告知“猫猫还没醒，这个我们也不敢动”，大肥鱼则在门缝里偷吃饼干。紫发猫耳女孩终于打着哈欠起床，笑问 GPT“早呀你怎么不进来”；GPT 急着指向门口让她“赶快给我拿走”，猫耳女孩低头才看见被自己遗忘在门外的苦力怕，尴尬地道歉。

**02｜sheet_003 + sheet_004｜00:24–00:47。** 紫发猫耳女孩连忙抱起还戴着眼罩的苦力怕让开门口，GPT 终于进屋，在室内工作台前把末影珍珠和从下界带回的烈焰棒材料制作成一颗颗绿色“末影之眼”。大肥鱼趴在台边盯着发亮的绿眼球，期待地说“这个看着好像糖”，种田女子赶紧把她抱起来，说“那个不能吃吃这个”，给她一块真正可食用的白色糖果/点心。GPT 收拾好几枚末影之眼，宣布“今天全员一起去末地门”，走到户外抛出一颗绿色末影之眼，让它漂浮指引寻找要塞/末地门的方向。

**03｜sheet_005 + sheet_006｜00:48–01:11。** GPT 投出的末影之眼在空中盘旋后落回村庄外的草地，大肥鱼匆匆跑出来盯着绿色光球，GPT 将它捡起并指向远方说“那个方向都跟上”。六位女孩——GPT、Claude、GLM、浅蓝发种田女子、紫发猫猫、大肥鱼——连同始终被猫猫抱着的苦力怕一起踏上寻找末地传送门的远足。穿过草坡野花丛时，种田女子忍不住落队采摘黄色花朵；其他人在前面继续赶路，成为下一段的掉队伏笔。

**04｜sheet_007 + sheet_008｜01:12–01:35。** GPT 板起脸警告后方的种田女子“再捡就把你留在这种地”，她慌忙把刚摘的花/零碎物品放下，连声认错“我错了我错了这就走”。前行时大肥鱼偷偷钻进 GLM 巨大的黑白蓬松尾巴，像被尾巴卷住般吊在半空，Claude 伸手将她抱出来，顺手提供零食面包和薯片，让一路奔波的她有东西吃。GLM 打哈欠摸自己的睡眠眼罩，疑惑“我们到了吗”；镜头切到海岸，大肥鱼跑到沙滩边远望漂浮在海面上空的紫色/绿色微光末影之眼，判断队伍可能需要渡海或继续追踪方向。

**05｜sheet_009 + sheet_010｜01:36–01:59。** 大肥鱼第一个兴奋跑向宽阔的海滩，高喊“哇大海啊哈”，沿着沙地奔跑，却一脚滑进海水，溅起巨大浪花，吓得种田女子赶来喊“大肥鱼你在哪啊”。Claude 指向海里，众人发现大肥鱼竟缩坐在一只巨大金属盆里漂浮，手里还抓着一条鱼边吃边玩。种田女子说“我们还以为你沉下去了”，大肥鱼毫不担心地回答“我只是有点饿”。**金属盆再进化为水上载具**，再次展现大肥鱼对盆的奇异用法。

**06｜sheet_011 + sheet_012｜02:00–02:23。** 种田女子望着无边海面发愁“这海我们怎么过去啊”。GLM 举起自己的一只高靴，说有“冰霜行者”，可以从水面走过去；Claude 则拿出常规方案，表示“我们坐船”，当场把一艘木划艇放到岸边。紫发猫猫抱着苦力怕追问“那我呢那我呢”，大肥鱼已经穿着女仆服在海里欢快游泳，喊人抱抱。Claude 先独自上船，种田女子接着也挤上去，委屈地抱怨“你抱轻一点啊”；紫发女孩也在岸边照看苦力怕和游来的大肥鱼，准备安排她们一起过海。

**07｜sheet_013 + sheet_014｜02:24–02:47。** Claude 划着木船载种田女子横渡海峡，种田女子坐在后面紧张地抱着她，Claude 催她“抓紧了”。大肥鱼却凭借自己鱼尾/水性游得极快，居然比划船还先游到对岸浅滩，得意自夸“这个就叫专业”；GPT 也惊讶“没想到你游得还挺快”。紫发猫猫抱着苦力怕说刚刚一路太刺激了；GLM 则踩着“冰霜行者”形成的一连串浮冰从海上走来，印证先前对靴子附魔的自述。GPT 飞到有粉色花树的另一片陆地继续投末影之眼，绿眼球在草地落下，大肥鱼又抢先跑过去捡起。
