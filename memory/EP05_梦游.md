**02｜sheet_003 + sheet_004｜00:24–00:47。** GPT 银白发龙娘从土坑里站起，严肃强调“挖三填一是每个 Minecraft 玩家的基本操作”，吐槽伙伴们过于娇气。大肥鱼独自跑到村庄铁傀儡脚边，提出不如直接“抢村民的”，铁傀儡忽然低头盯着她；她又天真地向傀儡招呼“嘿嘿早早上好呀”，傀儡似有回应，把她吓了一跳。浅蓝发种田女子及时过来把大肥鱼抱走，提醒“我们还是老老实实养羊做床吧”，随后两人在一群白羊附近活动，大肥鱼央求“让我也玩玩嘛”。**下一阶段的生存目标：获取羊毛、制作床。**

**03｜sheet_005 + sheet_006｜00:48–01:11。** 浅蓝发种田女子起初不愿让大肥鱼干扰养羊，结果仍把一枝麦穗交给她，自己站在旁边观察；大肥鱼挥舞麦穗，周围白羊顿时争先恐后追着她，瞬间把她团团围住、完全淹没。大肥鱼挥手呼救“克劳德救我”，镜头转到 Claude 已经围起的羊圈，几只羊在围栏内安静吃草，而大肥鱼缩在羊群里欲哭无泪。突显了大肥鱼的行动积极却总出状况，以及 Claude 的务实组织能力。

**04｜sheet_007 + sheet_008｜01:12–01:35。** Claude 靠近蹲在羊圈里的大肥鱼，轻拍或安慰她；鱼重新站起便得意说“我真厉害”，像是把养羊也算在自己头上。另一边，GLM 给 GPT 展示一个精致的金属指北针/罗盘，说“这个能带你找到要塞”。GPT 拿来查看，怀疑“这玩意不会坏了吧”；GLM 表示到下界就好用。紫发猫猫抱着戴眼罩的苦力怕指示方向“在那边”，GPT 展翼飞去侦察。黄昏时种田女子拿剪刀为羊剪毛，终于收获一大捧白羊毛，为做床迈出实质一步。**新关键道具：GLM 赠给 GPT 的要塞定位罗盘**，具体原理暂未说明。

**05｜sheet_009 + sheet_010｜01:36–01:59。** 种田女子剪好一大堆羊毛准备制床，Claude 也在村庄空地旁行动。蓝发大肥鱼站在空地上时，一座精致的灰黑色石质大宅突然从地基到屋顶迅速自动建成，她惊呼“房子几秒钟就能建好，那昨晚为什么要挖坑睡”；Claude 面无表情回“你们也没问啊”，暗示她早就有这种快速建房的方法。室内有书架与工作台，种田女子用羊毛制作了多张白色床并整齐排在墙边，Claude 认真逐张清点人数/床位，看起来察觉了数量不对。

**06｜sheet_011 + sheet_012｜02:00–02:23。** Claude 清点新房里做好的白床，突然指出“少一张”。大肥鱼主动说“我的床分你一半”，但 GLM 轻松表示“不用啦，我在下界都是站着睡的”，走到窗边，戴上自己的黑色睡眠眼罩，把蓬松大尾巴抱在身前，就这么站着睡着了。夜幕降临，浅蓝发种田女子盖着厚厚的羊毛被子睡在白床上，紫发猫耳女孩则侧躺着把戴眼罩的苦力怕紧紧抱在怀里一起睡。经过多集露宿/泥屋折腾，团队终于住进比较舒服的石屋；但 **GLM 特殊的站立睡眠习惯**成为新人物特色。

**07｜sheet_013 + sheet_014｜02:24–02:47。** 夜深了，浅蓝发种田女子躺在白床上辗转反侧，气恼地说“不行啊根本睡不着”。她看见 GLM 站在窗边戴眼罩、抱着尾巴睡觉，纳闷“站着不算睡觉，得躺床上”，GLM 睡眼惺忪地回应“哎我吗”。随后大肥鱼坐在一张床上，GLM 天真地说“那就打扰啦”；Claude 看出情况不对，过来把大肥鱼抱到自己床上，一同盖上被子睡下。GLM 低头望着这对同床而眠的同伴，心里似乎在回想刚才自己说了什么，最后终于选择躺在剩下的一张床上。角色的住宿分配以新的喜剧方式调整。

**08｜sheet_015 + sheet_016｜02:48–03:11。** GLM 自己钻进被窝准备睡觉，月夜却依旧寂静；种田女子再度怒醒，明确责怪“肯定是他，旁边有怪物就睡不了”。她指向紫发猫猫抱着的、仍在室内的苦力怕，猫猫辩解“他戴着眼罩呢，睡得可香了”，却还是抱着宠物离开住宅，蹲在门外轻声说“怕怕委屈你了”，把苦力怕放在草地上后自己走回屋。此时镜头特别拍到远处月下矗立着一座巨大的深色石头城堡/宅邸，**是新的环境线索，但现阶段无法断言谁居住、是否有敌人**。众人重新安静下来，种田女子终于能闭上眼睛入睡。
